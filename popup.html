      Statuses & colour tags

      Rename, recolour, add or remove pipeline stages. Tick "awaiting" for stages that mean you are waiting on the candidate; those feed the follow-up badge.

        Follow-up reminders

        Flag contacts in an "awaiting" status with no change for this many days. The count shows on the toolbar badge and the Due pill.

        Message snippets

        Reusable outreach templates. Variables {firstName}, {lastName}, {fullName}, {jobTitle}, {company}, {headline}, {location} fill from the contact and the current job when you copy.

          Import

          Import a CSV into the selected job. A header row is matched by name (Name, Headline, Company, Location, Profile URL, Status, Notes); duplicates within the job are skipped.

          Backup & restore

          A backup carries every job, contact and setting. Plain JSON is convenient; an encrypted .tlbak file is the offline way to move data between machines: carry the file yourself, nothing is uploaded.

          ATS export templates

          Export the selected job as candidate CSV shaped for a common ATS. Email and phone are left blank for you to fill; status carries through as the stage, source or tag.
